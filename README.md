<h1>CMOS Analog Comparator Design</h1>

<h2>Project Overview</h2>

<p>
This project presents the transistor-level design and simulation of a CMOS Analog Comparator. 
The comparator compares two analog voltages and produces a digital output depending on which input is larger.
</p>

<h3>Design Features</h3>

<ul>
  <li>Differential NMOS input pair</li>
  <li>PMOS active load</li>
  <li>Tail current biasing</li>
  <li>Gain stage</li>
  <li>CMOS output stage</li>
</ul>

<p>
The project demonstrates analog IC design flow including schematic implementation, transient analysis, 
DC sweep analysis, propagation delay measurement, and power calculation.
</p>
